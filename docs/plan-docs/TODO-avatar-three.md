## 소켓 규약 — 실제로 해보고 알게 된 것

| | |
| --- | --- |
| 이름 | `socket_head` · `socket_back` · `socket_neck`. 없으면 `head`·`torso`·`spine` 등으로 대체 탐색 |
| **높이를 숫자로 박으면 안 된다** | Kenney 는 `head` 뼈가 **목 근처**에 있다. 다른 팩은 정수리에 있다. 숫자를 박으면 모델을 바꾸는 순간 모자가 머리에 박힌다 |
| 치수는 **캐릭터 전체 바운딩 박스**로 잰다 | 뼈·빈 노드는 메시가 없어 박스가 **비어 있다.** 소켓 박스로 재면 아이템이 0 배율이 돼 사라진다 |
| 부모는 소켓, 치수는 루트 | 애니메이션을 따라가려면 부모는 뼈여야 한다 |
| 소켓의 회전·스케일을 되돌린다 | 안 하면 아이템이 뒤틀린다 |

🔴 **남은 한계** — 바운딩 박스 꼭대기는 **머리 꼭대기가 아니다.** 곰은 귀가, 사람은 머리카락이
더 높다. 그래서 모자가 살짝 뜬다. **`D4` 사양에 「소켓 이름」뿐 아니라 「아이템별 오프셋」도
넣어야 한다.** 규약이 90%를 해결하고 나머지 10%는 에셋 사양이 들고 있어야 한다.
